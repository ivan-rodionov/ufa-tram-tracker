# UfaTramTracker

Простой личный Android-прототип для маршрутов трамвая №5 и №16 в Уфе на данных `transportrb.ru`.

## Что умеет

- карта OpenStreetMap;
- показывает текущие позиции трамваев №5 и №16;
- показывает вагон, модель, скорость, направление и время навигации;
- обновляет данные каждые 15 секунд;
- показывает прибытия на остановку «Ул. Коммунистическая» в сторону Госцирка;
- показывает прибытия на остановку «Ул. Революционная» в сторону ул. Пушкина;
- SID можно заменить прямо в приложении, если текущий перестанет работать.

## Как собрать APK без Android Studio

1. Распаковать этот ZIP.
2. Создать пустой репозиторий GitHub.
3. Загрузить **содержимое** папки `UfaTramTracker` в корень репозитория. Важно загрузить и скрытую папку `.github`.
4. После коммита открыть вкладку **Actions**.
5. Открыть workflow **Build APK**. Он также автоматически запускается после push в `main`/`master`.
6. Если сборка не стартовала автоматически: **Run workflow → Run workflow**.
7. После зелёной галочки открыть запуск и скачать artifact **UfaTramTracker-debug-apk**.
8. В архиве artifact будет `app-debug.apk` — его можно установить на Android.

## Правильная структура репозитория

```text
.github/
  workflows/
    build-apk.yml
app/
  build.gradle.kts
  src/
build.gradle.kts
gradle.properties
settings.gradle.kts
README.md
```

Не должно быть дополнительной вложенности вида `UfaTramTracker/UfaTramTracker/app/...`.

## Важно

Это неофициальный прототип, использующий API, который вызывает веб-сайт `transportrb.ru`. Условия использования этого API отдельно не подтверждены.

В прототипе для соединения с `transportrb.ru` используется обход проверки цепочки TLS-сертификата, потому что при локальной проверке `curl` не смог проверить issuer. Для личного теста это оставлено намеренно; для публикации приложения так делать не следует.

Текущий SID может истечь. Если приложение пишет об ошибке сессии, открой `transportrb.ru`, в DevTools → Network найди `rpc.php`, скопируй значение `sid` и вставь его в поле приложения.
